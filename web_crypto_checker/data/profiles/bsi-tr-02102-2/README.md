# `data/profiles/bsi-tr-02102-2/` — BSI TR-02102-2 (TLS)

**BSI (Germany)**. The German federal TLS baseline targeting 120-bit security. AES-only suites (no ChaCha20), NIST/Brainpool curves and ffdhe3072+ (no x25519), RSA-PSS/ECDSA signatures, RSA/DH >= 3000-bit.
